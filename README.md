# hamzaalshamy.github.io

Personal site of Hamza Alshamy, served by GitHub Pages from `main`. Plain HTML, no build step: open `index.html` in a browser to preview.

- `index.html`: About (bio, research, select papers)
- `teaching.html`: teaching and mentorship, courses, materials
- `off-the-clock.html`: music, hiking, cooking
- `assets/pdf/Hamza_Alshamy_CV.pdf`: CV
- `assets/papers/`: paper PDFs, with first-page previews in `assets/img/papers/`

The previous al-folio site is kept on the `al-folio-archive` branch.
